# English Tycoon
Install Python 3.10+, then run `pip install -r requirements.txt` and `python server.py`. Open http://localhost:8000 on the teacher computer. Students on the same Wi-Fi use http://TEACHER-LAN-IP:8000 (allow port 8000 through firewall). For internet hosting deploy this folder to a Python web host, install requirements and start `waitress-serve --listen=0.0.0.0:$PORT server:app` (set PORT to host's assigned port). Use one process/instance; rooms are in memory and disappear on restart. Use HTTPS for public deployment. No hard-coded participant cap; load testing is needed. Keep teacher session token private. Export CSV before shutting down. Names/class are stored in memory only. Rejoin on same browser via local storage. No accounts. No public URL is included. Early finishers can review missed answers; no extra rewards. Question order randomized, option order fixed. QR and sound not implemented. Final customer bonus not implemented. VIP is first question of round 3, rush hour is mid-round 2, combo once per team. No persistent storage or cross-device recovery. Do not use multiple workers/instances without adding shared storage.
